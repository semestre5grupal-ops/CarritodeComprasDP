# Help ($?) — Plantilla

**Shortcut**: `$?`

**Description**: Muestra los atajos disponibles y guía para usar los comandos de workflow.

## Command

`$?`

## Instrucciones

1. Lista todos los atajos de workflow y sus descripciones. NO incluyas instrucciones detalladas.

2. Toma la tabla de workflows de `docs/ai_development/workflows/README.md` y muéstrasela al usuario.

3. Sugiere al usuario ejecutar `$prepare` si no lo ha hecho antes.

4. Sé conciso y usa lenguaje simple.

> **✏️ Personalización:**
> Si tu proyecto tiene workflows adicionales fuera de esta carpeta, menciónalos también.
